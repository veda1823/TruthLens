# TruthLens

AI-Powered Fake News Detection System

## About
TruthLens is a machine learning-based web application
that analyzes news articles and predicts whether the
content is potentially fake or reliable.

## Technology Stack
- Frontend: React.js
- Backend: Python, FastAPI
- Machine Learning: Scikit-learn, NLTK
- Database: MongoDB

## Features
- News classification
- Text analysis
- Prediction confidence score
- Analysis history
